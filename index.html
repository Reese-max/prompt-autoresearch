分組國考題庫資料夾 (questions/)

題庫分成 smoke、dev、holdout、final 四組。平常優化只看 smoke / dev；holdout 用來防止過度擬合，final 留給最後人工驗收。點選任一題可載入工作區進行單題預覽。

smoke.jsonl

快速確認候選提示詞沒有明顯跑版；分數低於 baseline 或硬性規則失敗就直接淘汰。

dev.jsonl

主要優化題庫。每類題型 6 題，用來比較平均分、題型退步與失敗碼分布。

holdout.jsonl

只在 dev 通過後才跑，必須在更新 baseline 前完成，避免候選只對 dev 題庫有效。

final.jsonl

人工驗收用，不參與平常自動演化；用來確認每日提示詞是否真的好用。

三重評分規準系統 (Triple Rubrics)

演化引擎使用嚴密的 100 分量表，對候選提示詞產出的答題正文進行全方位審查：

一、基礎申論分 (70分)
  • 題意命中 (15分)：精準鎖定並完整回答考題爭點。
  • 架構清楚 (10分)：一、(一)、1. 段落分明，結構對稱。
  • 採分點外露 (15分)：標題即答案，能吸引閱卷委員。
  • 內容具體 (15分)：包含核心法理、學理名詞與實務案例。
  • 考場語氣 (10分)：精煉客觀的學術/公務書寫語氣。
  • 結論回扣 (5分)：收尾並再次呼應考題核心。
二、題型專項分 (20分)
  • 說明題：概念定義、關聯圖譜與典型實例。
  • 比較題：明確列出比較基準，進行橫向整合。
  • 評析題：正面效益、負面限制與客觀評價。
  • 法律案例題：爭點列舉、法律依據、涵攝過程與結論。
  • 法律法理題：立法本旨、核心要件與司法實務意義。
  • 實務應用題：改善方案、具體工具與執行評估。
三、風險扣分 (10分)
  • 法條虛構 (-4分)：編造法條、司法院釋字或裁判字號。
  • 廢話反問 (-2分)：詢問使用者意見或出現對話引言。
  • 輸出審題 (-2分)：輸出內心審題思路或大綱。
  • 散文心得 (-2分)：以非申論題語調抒發個人情緒。

輸入您的 API Key 可以啟用 **真實 LLM API** 演化模式。所有演化演算都使用 Meta-prompt 重新改版系統提示詞，並使用目標金鑰直接對您的題目進行評分評估。

安全與架構說明

  • 本機存儲：金鑰與題目完全留在您的瀏覽器 local storage 內，不經由第三方伺服器。
  • 硬性規則防護：在 Live API 模式中，第一層過濾器仍會攔截有編造法條嫌疑或長度超標的候選提示詞，為您節省 token 成本。
  • 固定評估基準：題庫、rubric 與測試腳本是 ground truth metric；演化時只允許修改 prompt，不應改評分器換分數。
  • 可回溯決策：每輪會留下 summary 與 decision，方便追查候選為何 ACCEPT 或 REVERT。
